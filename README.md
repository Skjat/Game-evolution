# Level Up — прокачка себя как RPG-персонажа

Приложение для iPhone (PWA): по итогам дня начисляешь очки своим параметрам —
Сила, Ловкость, Выносливость, Интеллект, Мудрость, Харизма (список можно менять) —
и смотришь, как растёт твой персонаж.

## Темы оформления
Ещё → **Тема оформления** — пять тем разной направленности:
- **Алый реактор** — тёмное техно-фэнтези: алые и оранжевые лазеры, неоновые отсветы, ядро реактора с вращающимися кольцами.
- **Минимал** — светлый спокойный дизайн без свечения и эффектов, мягкие тени, аккуратные цвета.
- **Терминал** — ретро-консоль: зелёный текст на чёрном, моноширинный шрифт, развёртка, мигающий курсор, сегментные шкалы.
- **Дзен** — тёплая тёмная тема в тонах шалфея и песка, медленно «дышащий» свет и плывущие частицы.
- **Чёрный гримуар** — в духе аниме «Чёрный клевер»: тёмно-зелёная антимагия, золотой магический круг, гримуар с четырёхлистным клевером.

У каждой темы свой набор иконок параметров, нижнего меню и кнопок: в «Минимале» — гиря, бегун, лампочка, сова;
в «Терминале» — пиксельные (батарея, процессор, уровень сигнала); в «Дзене» — гора, волны, бамбук, фонарь, энсо, сакура;
в «Чёрном гримуаре» — большой меч, вихрь, гримуар, магический круг, бык, знамя отряда.
Все иконки можно выбрать и вручную в настройках параметров.

У каждой темы свои шрифты, палитра параметров, аватар по умолчанию и тексты кнопок и анимаций
(«Зарядить ядро» / «Подвести итоги дня» / «> run daily_report» …). При смене темы цвета и иконки параметров и аватар
меняются, если ты не менял их вручную. Тема хранится на телефоне и в резервной копии.
Анимации отключаются, если на iPhone включено «Уменьшение движения».

## Возможности
- **Герой** — уровень и звание персонажа, шкала опыта, радар параметров, серия дней 🔥.
- **Итоги дня** — «подвиги» (тренировка, чтение, новое знакомство…) начисляют очки в один тап;
  можно писать заметку и редактировать прошлые дни. Вручную очки параметрам не начисляются — только подвиги и ИИ-отчёт,
  чтобы никто случайно не накрутил себе параметры. Подвиг даёт не больше 5 очков в параметр и засчитывается не больше 3 раз за день.
  Очки от ИИ видны отдельным списком — их можно убрать, если ИИ ошибся.
- **История** — график очков за 7 / 30 / 90 дней и дневник.
- **Награды** — 263 встроенных достижения по сферам жизни плюс свои (см. ниже).
- **Настройки** — имя и аватар, свои параметры и подвиги, экспорт/импорт резервной копии.
- Работает офлайн, данные хранятся только на телефоне.

Правило уровней: чтобы параметр перешёл с уровня N на N+1, нужно 10×N очков.

## Достижения (263)
- **Путь героя** — 20 системных наград: серии дней, уровни, баланс параметров.
- **46 цепочек в 11 сферах жизни** (Тело, Здоровье, Разум, Общение, Карьера, Финансы, Творчество,
  Приключения, Дом, Дух, Добро): прочитанные книги, километры бега, новые знакомства, часы учёбы,
  страны, медитации… У каждой цепочки 3–6 ступеней редкости: бронза → серебро → золото → платина → легенда → миф.
- **61 разовая веха**: марафон, прыжок с парашютом, финансовая подушка, своя песня, сдал кровь и т.д.

**Свои достижения.** В любой сфере на экране «Награды» есть кнопки «Своя цепочка» и «Своя веха»:
название, единица, подсказка «что считается», символ и до 6 ступеней со своими порогами.
ИИ видит свои достижения наравне со встроенными и начисляет по ним прогресс. Они сохраняются в экспорте.

Счётчики растут от подвигов (тренировка → «Тренировки» +1), вручную (кнопка «+» у цепочки) или от ИИ-отчёта.
Встроенная база — в `achievements-db.js`.

## Слабости, штрафы и позор
- **Слабости** (экран «Итоги») — вредные действия: фастфуд, сладкое, алкоголь, курение, пропуск тренировки,
  день на диване, залипание в телефоне, прокрастинация, недосып, хамство, импульсивные покупки, опоздания.
  Сама слабость очков не отнимает — она пополняет цепочку позора. На карточке видно, сколько осталось до следующего клейма и чем оно грозит.
  Список редактируется в «Ещё → Слабости».
- **Позор** — цепочки антидостижений с унизительными ступенями: «Жирдяй» → «Жиробас» → … → «Сальная легенда»,
  «Диванный воин» → «Слабак» → «Тряпка» и т.д. Клейма не входят в общий счёт наград.
- **Штрафы — только за клейма.** Первая ступень клейма — предупреждение без штрафа. Дальше каждая новая ступень бьёт по параметрам
  этой слабости: −5, −10, −20, −30, −50 (основным параметрам слабости — полностью, второстепенным — половина).
  Позорная веха («Провал в памяти», «Слился в последний момент»…) — разово −10 к связанным параметрам.
- **Деградация** — если штраф опускает параметр или персонажа ниже порога, уровень падает (отдельная анимация и звук).
- **Искупление**: 14 «чистых» дней без слабости снимают одну ступень клейма и **возвращают её штраф** — «Сальная легенда» (100)
  откатывается к «Повелителю бургеров» (60), ещё 14 дней — к «Королю фритюра» (30) и так до нуля.
  Считаются только дни, когда ты заполнял итоги; пропущенные не засчитываются, но и не обнуляют. Срыв обнуляет отсчёт.
- **15 цепочек позора**, в том числе «Ночной дожор» (Ночной хомяк → … → Чревоугодник), «Обжорство» (Проглот → … → Чёрная дыра)
  и «Энергетики и лишний кофе» (Кофеман на взводе → … → Сердце-пулемёт).
- **Позорные вехи** — 12 разовых провалов: «Провал в памяти», «Слился в последний момент», «Проспал важное», «Абонемент-призрак»…
  Можно добавить свою позорную веху.
- **Антисерии**: «Рецидивист», «Хроник», «Безнадёжный случай» — 3, 7 и 14 дней подряд одна и та же слабость;
  «Рецидив» — срыв после 30+ чистых дней.
- **Позор недели** в лиге: метка у того, у кого больше всех слабостей за прошлую неделю (при равенстве — больше штрафов за клейма); держится до следующего понедельника.
- Дни, где были только слабости, не продлевают серию. ИИ тоже фиксирует слабости и счётчики позора, но очков за вред не снимает.

## ИИ-отчёт за день
Вечером нажми «Рассказать о дне ИИ» на экране «Итоги», надиктуй, что сделал, — ИИ начислит очки параметрам,
отметит подвиги, счётчики и вехи. Перед применением показывается список с галочками: всё можно проверить и снять.

Провайдеры (Ещё → ИИ-помощник):
- **Claude** — нужен API-ключ с [platform.claude.com](https://platform.claude.com) → API Keys.
  Вызов идёт через официальный SDK `@anthropic-ai/sdk` (собран в `vendor/anthropic-sdk.mjs`) прямо с телефона;
  модель по умолчанию — Claude Opus 5.5, ответ строго по JSON-схеме, включён серверный fallback на случай
  ошибочного отказа классификатора безопасности. Один отчёт стоит порядка нескольких центов.
- **Свой сервер** — любой OpenAI-совместимый API (`/v1/chat/completions`): Ollama, vLLM, llama.cpp, LM Studio,
  например с моделью Hermes. Сервер должен быть доступен по HTTPS и разрешать CORS для адреса приложения
  (для Ollama: `OLLAMA_ORIGINS=https://skjat.github.io`).

Ключи хранятся только на устройстве и не попадают в экспорт. Текст отчёта отправляется выбранному провайдеру.

## Звук
Эффекты синтезируются через Web Audio (`sound.js`), без аудиофайлов. Выключаются в «Ещё → Звук».
На iPhone звук молчит в беззвучном режиме.

## Лига друзей (онлайн)
Вкладка «Лига»: таблица XP за неделю, суд лиги (доносы и похвалы с голосованием) (сброс в понедельник, корона чемпиону прошлой недели), уровни, серии и
коллекции позора, лента достижений, клейм и срывов с реакциями «Респект» и «Позор».
На сервер уходит только сводка игрока; заметки и подробности дней остаются на телефоне.
Друг вступает по приглашению вида `ABCD-EFGH@levelup.<поддомен>.workers.dev`.
Код восстановления переносит участие на другой телефон.
Если лига пишет «Нет связи», а включён VPN — выключи его или добавь `workers.dev` в исключения: DNS некоторых VPN не находит адреса `*.workers.dev`.

**Общие достижения лиги.** Своё достижение можно отдать лиге: переключатель «Поделиться с лигой» при создании
или кнопка «В лигу» в его карточке. Оно появляется у всех участников в сфере «Лига» (позорные — в «Позоре»),
каждый может его получить, а ИИ учитывает его наравне со встроенными. Автор может убрать его из лиги —
у тех, кто уже начал его выполнять, оно останется как своё вместе с прогрессом.

**Суд лиги: доносы и похвалы.** В карточке участника (вкладка «Лига» → нажми на игрока) есть кнопки «Донести» и «Похвалить».
Расскажи текстом или голосом, что он сделал (сегодня, вчера или позавчера), — твой ИИ превратит рассказ в отчёт за день:
подвиги, слабости, счётчики, вехи и запись в дневник. Отчёт уходит на голосование в раздел «Суд лиги».
Голосуют все, кроме того, о ком отчёт (если в лиге только двое — решают оба), голос автора засчитывается сразу «за».
Нужно большинство: больше половины голосующих. На голосование даётся 3 суток (в карточке идёт обратный отсчёт): если большинство
за это время не набралось, решение выносится по текущим голосам — «за» больше, чем «против», значит утверждено, иначе (и при равенстве) обвиняемый оправдан.
Автор может отозвать отчёт, пока идёт голосование.
Утверждённый отчёт телефон участника сам добавляет в нужный день при следующей синхронизации — с пометкой «лига · автор»,
а в дневник пишется строка «⚖ Решение лиги». Слабости из доноса копят позор по обычным правилам клейм,
а сверх того утверждённый донос сразу даёт **штраф суда −3**, а похвала — **бонус +3** в каждый из двух самых затронутых параметров
(для доноса — по слабостям из отчёта, для похвалы — по наградам подвигов).
Нужен настроенный ИИ (Claude или свой сервер). Одновременно у автора может быть до 5 открытых голосований.
В карточке голосования видно, кто голосует и как уже проголосовал. «Суд лиги · нужен твой голос» и красный значок на вкладке
«Лига» появляются только у тех, чей голос ещё ждут: у автора голос засчитан сразу, а тот, о ком отчёт, не голосует (кроме лиги из двух).

**Цепочки суда.** Считаются автоматически по итогам твоих доносов (вручную и через ИИ их не накрутить):
- «Поборник справедливости» (сфера «Лига») — доносы, которые лига утвердила: Свидетель (1) → Бдительный гражданин (3) → Страж порядка (6) →
  Поборник справедливости (10) → Карающая длань (20) → Верховный судья (35).
- «Ябеда / крыса» (сфера «Позор») — доносы, которые лига отклонила (в том числе оправдание по истечении 3 суток): Ябеда (2) → Стукач (4) →
  Крыса (7) → Крысиный король (12) → Позор лиги (20). Это обычная цепочка позора: со второй ступени клейма бьют по Харизме (и вполовину по Мудрости),
  14 чистых дней снимают ступень. Отозванные автором доносы не считаются.

**Исключение из лиги.** Основатель лиги (самый давний участник) может исключить участника: карточка участника → «Исключить из лиги».
Прогресс на телефоне исключённого остаётся, а в лиге он пропадает; вернуться можно только по новому приглашению.

**ИИ предлагает новые достижения.** Если в отчёте есть занятие, которого нет в каталоге (например, горные лыжи),
Claude в окне разбора предлагает создать цепочку и/или веху и сразу засчитать прогресс — с галочкой «Поделиться с лигой».

### Сервер лиги на своём сервере (без Cloudflare)
Тот же сервер (`server/worker.js`), но на Node.js с базой SQLite (`server/node/server.mjs`), в Docker.
На сервере с Linux выполни одну команду:
```bash
curl -fsSL https://raw.githubusercontent.com/Skjat/Game-evolution/main/server/install.sh | sudo bash
```
Скрипт поставит Docker (если его нет; docker compose не нужен), скачает сервер в `/opt/levelup`, запустит его и Caddy с автоматическим HTTPS.
Без своего домена используется бесплатный адрес вида `1-2-3-4.sslip.io`; со своим —
`... | sudo DOMAIN=league.example.ru bash`. Если порты 80/443 заняты (nginx и т.п.), сервер запустится на
`127.0.0.1:8787`, а скрипт покажет, что добавить в конфиг веб-сервера. В конце выводится адрес для приложения
(вкладка «Лига» → «Адрес сервера»). Повторный запуск обновляет сервер, данные хранятся в `/opt/levelup/data`.

### Развёртывание сервера в Cloudflare (один раз)
Сервер — `server/worker.js` (Cloudflare Worker) + база D1 (`server/schema.sql`). Его разворачивает GitHub Actions
(`.github/workflows/deploy-server.yml`) при каждом изменении папки `server/`.
1. Зарегистрируйся на cloudflare.com, открой **Workers & Pages** и выбери поддомен `*.workers.dev`.
2. Скопируй **Account ID** (Workers & Pages → справа «Account details»).
3. **My Profile → API Tokens → Create Token** → шаблон **Edit Cloudflare Workers** → добавь разрешение
   **Account → D1 → Edit** → Create Token.
4. В GitHub: **Settings → Secrets and variables → Actions** → секреты `CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_ACCOUNT_ID`.
5. **Actions → Deploy league server → Run workflow**. В итогах запуска будет адрес сервера:
   `https://levelup.<поддомен>.workers.dev`.

Бесплатного тарифа Cloudflare (100 000 запросов в день) с запасом хватает на лигу друзей.

## Установка на iPhone
1. Включи GitHub Pages: репозиторий → **Settings → Pages** → Source: **Deploy from a branch**,
   Branch: **main**, папка **/ (root)** → Save. Через минуту сайт будет доступен по адресу
   `https://skjat.github.io/Game-evolution/`.
2. Открой этот адрес на iPhone в **Safari**.
3. Нажми **«Поделиться»** → **«На экран „Домой“»** → «Добавить».

## Локальный запуск
```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Файлы: `index.html`, `style.css` (темы и анимации), `app.js` (логика, экраны, иконки),
`achievements-db.js` (база достижений), `ai.js` (ИИ-отчёт), `league.js` (лига), `sound.js` (звуки),
`server/` (сервер лиги для Cloudflare),
`vendor/` (Anthropic SDK, лицензия Apache 2.0),
`sw.js` (офлайн-кэш), `manifest.webmanifest`, `icons/`, `fonts/` + `fonts.css`
(Unbounded, Exo 2, JetBrains Mono, Jura, Cormorant SC, Ruslan Display — лицензия SIL OFL, встроены для работы офлайн).
При изменении файлов увеличь `VERSION` в `sw.js` и `APP_VERSION` в `app.js` — приложение само подхватит обновление.
Текущая версия видна внизу экрана «Ещё», а версия друзей — в их карточке в лиге.
